# Jarvis Media Mini App

Mini App tĩnh cho Telegram Jarvis.

Hỗ trợ:
- YouTube embed
- MP4 / WebM / HLS (.m3u8)
- Safe Web sandbox

Giới hạn:
- Không vượt DRM/paywall/login/embed restrictions.
- Không can thiệp quảng cáo được phân phối bên trong YouTube player.
- GitHub Pages bỏ qua file _headers của Cloudflare, nên dự án này dùng HTML/JS/CSS thuần.
